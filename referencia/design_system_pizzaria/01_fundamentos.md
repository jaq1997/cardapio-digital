# Design System: Pizzaria "Hut Style" - Fundamentos

Este documento define os pilares visuais baseados na identidade da Pizza Hut Brasil.

## 1. Cores (Design Tokens)

A paleta é dominada pelo vermelho vibrante, equilibrado com tons neutros escuros e brancos limpos.

| Token | Valor Hex | Uso |
| :--- | :--- | :--- |
| `--color-brand-primary` | `#E91C24` | Cor principal (Vermelho Hut) |
| `--color-brand-dark` | `#C50303` | Hover de botões e acentos escuros |
| `--color-neutral-black` | `#1E1E1E` | Textos principais e fundos escuros |
| `--color-neutral-white` | `#FFFFFF` | Fundos e textos inversos |
| `--color-neutral-gray` | `#F4F4F4` | Fundos secundários e bordas leves |
| `--color-success` | `#0A7A67` | Mensagens de sucesso e confirmação |

## 2. Tipografia

O sistema utiliza uma combinação de fontes robustas para títulos e legíveis para corpo.

*   **Títulos (Display):** `RLAqva` (ou similar Sans-Serif Black/Heavy). Foco em peso 900.
*   **Corpo de Texto:** `Source Sans 3` ou `Inter`. Foco em pesos 400 (Regular) e 600 (Semi-bold).

| Escala | Tamanho | Peso | Uso |
| :--- | :--- | :--- | :--- |
| `Heading L` | `44px` | `900` | Títulos de Hero / Banners |
| `Heading M` | `32px` | `700` | Títulos de Seção |
| `Body Base` | `16px` | `400` | Texto corrido / Descrições |
| `Button Text` | `14px` | `600` | Rótulos de botões |

## 3. Espaçamento e Raio

*   **Grid:** Base de `4px` ou `8px`.
*   **Border Radius:**
    *   `Small`: `4px` (Inputs)
    *   `Medium`: `8px` (Cards)
    *   `Large`: `24px` ou `Full` (Botões Pill-shape)
